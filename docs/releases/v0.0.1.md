# v0.0.1

The first tag of recordprims: the foundation of a durable record store for the
`durable-record/v1` contract, in pure Go. It is pre-release; the API will
change before 0.1.0.

## What it ships

- **Go module** `github.com/3leaps/recordprims`, cgo-free, on Go 1.26 or
  later. No package is published to a registry, and the Rust crate is not
  published in this release.
- **Store foundation.** `Init` creates a store and `Open` verifies one: the
  root is opened once as a confined directory handle, refuses symlinks,
  special files and hard links, and must be owned by the current user. On
  Unix it allows no group or other access; on Windows its DACL may grant
  access only to its owner, SYSTEM and the local administrators. The root must be
  on a local filesystem from an allowlist: APFS or HFS+ on macOS, ext4, XFS
  or Btrfs on Linux, NTFS or ReFS on Windows.
- **Store lock.** One cross-process lock, held through the confined root,
  serializes mutations; it fails fast by default and is released by the
  operating system if the holder exits.
- **Bodies.** `PutBody` and `RemoveBody` store content-addressed bytes with
  per-publication leases, incarnation records and retention tombstones. Both
  derive their behavior from one body-state function and are idempotent by
  state: an error after a durable step returns `ErrBodyIncomplete`, and
  retrying the same call completes it. Until stream protection checks exist,
  `RemoveBody` reports `protection_unknown` whenever any stream is present.
- **Errors** in two published sets, determinate and indeterminate
  (`IsIndeterminate`), that carry no paths.

Records, the journal, restrictions and release are not yet implemented.

## Platforms

CI runs the full gate natively on linux amd64/arm64, darwin arm64 and windows
amd64/arm64, and builds and tests the Go module on its own, outside the
repository.

## Verification

This release is one signed annotated tag, `v0.0.1`. Verify it against the
public pins committed in the tagged commit (`docs/security/`,
`keys/expected-fingerprints.*`); see `docs/security/README.md`.
